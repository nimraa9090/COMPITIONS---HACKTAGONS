## Featured Competitions

### 1. Titanic: Machine Learning from Disaster

* **Domain:** Binary Classification / Predictive Analytics
* **Goal:** Predict passenger survival on the Titanic using demographic and travel data (age, sex, class, fare, etc.).
* **Key Steps:**
* Exploratory Data Analysis (EDA) and missing value imputation.
* Feature engineering (extracting titles, family size, fare bins).
* Model comparison using logistic regression, decision trees, random forests, and gradient boosting algorithms.
